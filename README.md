# Portofolio Personal — Reyvann

Website portofolio interaktif dan responsif milik **Reyvann** — *Web Developer & UI/UX Enthusiast*. Dibangun hanya dengan **HTML5**, **CSS3**, dan **JavaScript murni (Vanilla JS)**. Siap di-deploy ke GitHub Pages.

## Fitur

- Navbar sticky dengan **6 menu**: Beranda, Tentang, Keahlian, Proyek, Pendidikan, Kontak, serta tombol **Hubungi Saya**
- Menu navigasi mobile dan penanda section aktif
- Hero: judul **Halo, Saya Reyvann**, deskripsi, tombol **Lihat Proyek** dan **Unduh CV**
- Section Tentang, Keahlian, Proyek, dan Pendidikan
- Form kontak (Nama, Email, Pesan) dengan validasi dan pop-up sukses buatan

- Tema **Dark Cinematic** dengan dark glassmorphism dan aksen cahaya emas
- Foto hero: `foto-profil.jpg`

## Struktur File

- `index.html` — struktur halaman
- `style.css` — tema gelap dan responsivitas
- `script.js` — interaksi
- `README.md` — panduan ini
- `foto-profil.jpg` — foto utama

## Menjalankan Lokal

Buka `index.html` atau jalankan `python -m http.server 8000`, lalu kunjungi `http://localhost:8000`.

## Deploy GitHub Pages

1. Buat repository **Public**, lalu upload kelima file di atas ke root repository.
2. Buka **Settings → Pages**.
3. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**.
4. Klik **Save**, tunggu beberapa menit, lalu buka `https://USERNAME.github.io/NAMA-REPO/`.

## Catatan

Form kontak hanya berjalan di browser (demo). Ganti tautan Unduh CV dan tautan proyek dengan asli bila tersedia.
